# Research commerce: direct Stripe checkout
The new prototype uses Stripe Checkout, with no Wix purchase fallback. The live Wix store remains untouched until approved cutover. Preview accepts test keys only. Test events never unlock paid PDFs. Production requires REPORTS_LIVE_CHECKOUT=true, live key, REPORTS_PUBLIC_ORIGIN, webhook signing secret, Resend key, private Blob token, signing secret and report object. Use separate test and live credentials and storage.
Preview amounts reflect the last verified Wix catalog ($2,700 for 2026, $2,250 for 2025); older draft prices were $3,000 and $2,750. Confirm all final prices before launch. Inline Stripe price_data is used.
Configure STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, RESEND_API_KEY, BLOB_READ_WRITE_TOKEN, DOWNLOAD_SIGNING_SECRET, REPORTS_PUBLIC_ORIGIN in Vercel securely. Do not put secrets in GitHub. Verify Stripe webhook access for protected preview deployments. Use a dummy PDF to test full fulfillment independently of paid documents.
Fulfillment checks signature, store tag, paid status, amount and currency. Live email uses Resend idempotency and Stripe session fulfillment metadata; failed delivery returns non-2xx for retry. A durable ledger, reconciliation, refund procedures, tax settings, receipt and license validation, and end-to-end payment and delivery tests remain production gates. Migrate report artwork currently hosted on Wix to controlled storage before decommissioning. Free sample and custom benchmarking flows also require end-to-end validation.
